Data downloading, labeling, converting and uploading tool in Ren'py. In order to run it, you have to download the Ren'py SDK and execute it that way. Illustration source: https://www.dlsite.com/home/work/=/product_id/RJ195890.html
Additionally, you have to install packages listed in requirements.txt to the game/python-packages directory (use pip install --target={python-packages directory path})
